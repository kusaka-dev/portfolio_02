コーディングテンプレート

Vite + EJS + SCSSを使用したモダンなWeb開発テンプレートです。
効率的な開発環境で、素早くプロジェクトを立ち上げることができます。

含まれる機能

  • Vite - 高速な開発サーバーとビルドツール
  • EJS - コンポーネントベースのテンプレートエンジン
  • SCSS - 変数、ミックスイン、ネストに対応したCSSプリプロセッサ
  • グロブインポート - SCSSファイルの自動インポート
  • モダンCSS Reset - アクセシビリティに配慮したリセットCSS

使い方

  1. 依存関係のインストール: npm install
  2. 開発サーバーの起動: npm run dev
  3. 本番ビルド: npm run build

プロジェクト構成

  • src/ - ソースファイル
  • src/components/ - EJSコンポーネント
  • src/assets/styles/ - SCSSファイル
  • src/assets/scripts/ - JavaScriptファイル
  • dist/ - ビルド出力先
